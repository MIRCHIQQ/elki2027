# Ёлочный Бал

Одностраничный магазин новогодних украшений: ёлки, стеклянные шары, гирлянды и декор. Чистый HTML, CSS и JavaScript, без сборки и зависимостей.

## Что внутри

- анимация захода: шар на нитке, «двери» раскрываются и показывают главный экран
- плавная навигация по разделам, полоса прокрутки со звёздочкой, появление блоков при прокрутке
- включение и отключение снега кнопкой в шапке (выбор запоминается в браузере)
- каталог из 15 товаров с фильтрами, сортировкой и тремя подборками
- корзина с количеством, суммой и прогрессом до бесплатной доставки
- таймер до 1 января (считается автоматически для ближайшего Нового года)

Иллюстрации товаров нарисованы кодом (inline SVG), внешних картинок нет. Шрифты (Manrope, Marck Script, Yeseva One) подключаются с Google Fonts.

Сайт демонстрационный: оформление заказа ничего не отправляет, цены и описания придуманы.

## Структура

```
index.html          разметка страницы
assets/style.css    стили и цвета (переменные в :root)
assets/app.js       товары, корзина, снег, анимации
assets/favicon.svg  иконка
.nojekyll           отключает обработку Jekyll на GitHub Pages
```

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен на http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий, например `elochny-bal`.
2. Загрузите файлы:

   ```bash
   git init -b main
   git add .
   git commit -m "Ёлочный Бал: новогодний магазин"
   git remote add origin https://github.com/<ваш-логин>/elochny-bal.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт появится по адресу `https://<ваш-логин>.github.io/elochny-bal/`.

Все пути в проекте относительные, поэтому сайт работает и в подпапке репозитория.

## Как менять содержимое

- **Товары, цены, подборки.** В начале `assets/app.js` массив `P` (товары) и массив `SETS` (подборки). У товара есть поля `name`, `desc`, `price`, необязательные `old` (старая цена) и `tag` (метка), категория `cat` (`tree`, `toys`, `lights`, `decor`) и подборка `set`.
- **Цвета и шрифты.** Переменные в блоке `:root` в начале `assets/style.css`.
- **Снег по умолчанию.** В конце `assets/app.js` строка с `setSnow(...)`: поставьте `false` вместо `!reduce`, чтобы снег был выключен при первом заходе.
- **Дата Нового года.** Функция `countdown()` в `assets/app.js`.
- **Условия доставки.** Порог бесплатной доставки задаёт константа `FREE_FROM`, тексты в разделе «Доставка» лежат в `index.html`.
